# Python Prep

A step-by-step practice track for learning Python. Each topic has:

- a **lesson** file: examples you run and read
- an **exercises** file: functions you complete, plus built-in checks

## How to use

```bash
cd python-prep
python3 00_basics_challenges.py # start here: 20 beginner challenges
python3 01_lists_lesson.py      # read the output alongside the code
python3 01_lists_exercises.py   # fill in the TODOs, re-run until all pass
```
